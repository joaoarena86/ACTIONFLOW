┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ 📋 SOBRE O PROJETO                                                                                                                    │
├─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                                                                       │
│  ActionFlow é um gerenciador de workflows profissional com design premium glassmorphism.                                              │
│  Organize projetos, objetivos, etapas sequenciais, sub-etapas e comentários.                                                          │
│                                                                                                                                       │
└─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ ✨ FUNCIONALIDADES                                                                                                                    │
├─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                                                                       │
│  🔐 Autenticação       → Login e registro com localStorage                                                                            │
│  📁 Workflows          → Criar, selecionar e excluir workflows                                                                        │
│  🎯 Objetivos          → Título, descrição, data, prioridade (alta/média/baixa)                                                       │
│  📌 Etapas Sequenciais → Etapa só libera após concluir a anterior                                                                     │
│  ✅ Sub-etapas         → Checklist dentro de cada etapa                                                                               │
│  💬 Comentários        → Adicionar comentários por etapa                                                                              │
│  📊 Dashboard          → Estatísticas + gráfico de barras de todos workflows                                                          │
│  📈 Gráficos           → Chart.js com progresso de workflows e etapas                                                                 │
│  🕒 Relógio            → Data e hora em tempo real                                                                                    │
│  ⚙️ Configurações      → Alterar senha, excluir conta, excluir todos workflows                                                        │
│                                                                                                                                       │
└─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

├─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                                                                       │
│  1️⃣ Baixe o arquivo actionflow.html                                                                                                  │
│  2️⃣ Clique duas vezes no arquivo (abre no navegador)                                                                                 │
│  3️⃣ Clique em "Criar Conta" e digite usuário e senha (mínimo 4)                                                                      │

┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ 📖 COMO USAR                                                                                                                          │
├─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                                                                       │
│  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐    │
│  │ WORKFLOWS                                                                                                                      │    │
│  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤    │
│  │  Criar        → Digite o nome e clique em "Criar"                                                                              │    │
│  │  Selecionar   → Clique no workflow desejado na lista                                                                           │    │
│  │  Excluir      → Selecione o workflow e clique em "Excluir"                                                                      │    │
│  │  Salvar e Sair → Dentro do workflow, clique em "💾 Salvar e Sair"                                                              │    │
│  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘    │
│                                                                                                                                       │
│  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐    │
│  │ OBJETIVOS                                                                                                                     │    │
│  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤    │
│  │  Adicionar   → Preencha título, descrição, data, prioridade e clique em "+"                                                   │    │
│  │  Concluir    → Marque o checkbox                                                                                              │    │
│  │  Editar      → Clique no ícone de lápis                                                                                        │    │
│  │  Excluir     → Clique no botão "Excluir"                                                                                       │    │
│  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘    │
│                                                                                                                                       │
│  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐    │
│  │ ETAPAS                                                                                                                       │    │
│  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤    │
│  │  Adicionar   → Preencha nome, descrição, data e clique em "+"                                                                 │    │
│  │  Concluir    → Clique em "✅ Concluir"                                                                                         │    │
│  │  Reabrir     → Clique em "🔄 Reabrir" (etapas concluídas)                                                                      │    │
│  │  Excluir     → Clique em "🗑️ Excluir"                                                                                          │    │
│  │  Ver detalhes → Clique em "📋 Detalhes"                                                                                        │    │
│  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘    │
│                                                                                                                                       │
│  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐    │
│  │ SUB-ETAPAS E COMENTÁRIOS                                                                                                      │    │
│  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤    │
│  │  Sub-etapas   → Dentro dos detalhes da etapa, digite e clique em "+"                                                          │    │
│  │  Comentários  → Dentro dos detalhes da etapa, digite e clique em "Enviar"                                                     │    │
│  └─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘    │
│                                                                                                                                       │
│  ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐    │

│  ├─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤    │
│  │  Alterar senha           → Configurações → Segurança                                                                          │    │
│  │  Excluir TODOS workflows → Configurações → Perigo → Excluir TODOS                                                             │    │
│  │  Excluir conta           → Configurações → Perigo → Excluir Conta                                                             │    │
